# Fumigation and Cleaning Service Booking and Tracking System

## Project Description
The Fumigation and Cleaning Service Booking and Tracking System is a Python-based application developed to help customers book cleaning and fumigation services, make payments, track service progress, receive digital receipts, and provide feedback.

The system also allows administrators or staff to securely access the system, view bookings, search for booking records, update service status, and view customer feedback.

## Main Features
- Customer registration
- Gmail validation
- Customer account access
- View available services
- Book one service
- Book multiple services
- Pickup and on-site service management
- Automatic service cost calculation
- 5% discount calculation
- 50% initial payment for pickup services
- 40% initial payment for on-site services
- Booking tracking
- Payment processing
- Digital receipt generation
- 1–5 star customer rating
- Customer comments
- Administrator password protection
- Booking status updates
- Text-file data storage

## How to Run the Program
1. Install Python on the computer.
2. Open the project folder in Visual Studio Code.
3. Open `fumigation_cleaning_system.py`.
4. Run the Python file.
5. Use the displayed menu to access the Customer or Administrator/Staff section.

## Project Purpose
The purpose of this project is to provide a simple computerized solution for managing fumigation and cleaning service bookings, payments, tracking, receipts, and customer feedback.
